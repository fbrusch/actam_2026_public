A synth in Python

The page holds the buttons and the sliders; the sound is made by the Python below, in the browser, with sounddevice. The callback fills each block of samples a little ahead of time, and the page plays them.

Keys A W S E D F T G Y H U J K on the keyboard play too.

THE PYTHON

IN YOUR OWN PAGE

Any page, or a pen on CodePen, can do the same with one import:

<button id="audio">audio</button>
<script type="module">
import { startPython } from 'https://actam.bruschi.dev/pysound/pysound.js'

const py = await startPython({ button: '#audio' })   // Pyodide, numpy, sounddevice
await py.runPythonAsync(`
import numpy as np
import sounddevice as sd

phase = 0
def callback(outdata, frames, time, status):
    global phase
    n = phase + np.arange(frames)
    outdata[:, 0] = 0.2 * np.sin(2 * np.pi * 440 * n / 48000)
    phase += frames

stream = sd.OutputStream(samplerate=48000, blocksize=256, channels=1, callback=callback)
stream.start()
`)
</script>

From the page's JavaScript, py.runPython("stream.stop()") or py.globals.get("name") reach the Python.
