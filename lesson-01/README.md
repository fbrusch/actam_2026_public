# Lesson 01: Python as a conversation

Download or open `notebook.ipynb` in Jupyter or Colab. Run the cells in order. Audio players require a click and do not autoplay.

The notebook uses Matplotlib and IPython. Its optional direct playback example uses sounddevice and an available audio output device.

The companion presentation is `slides.md`. It includes exercises, speaker notes, and an interactive browser sample lab. To run it locally, install the repository dependencies from the root and run:

```sh
npx slidev lesson-01/slides.md
```
